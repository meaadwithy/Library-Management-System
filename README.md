
# Library System (Swift)

A command-line library management application built in Swift demonstrating Object-Oriented Programming (OOP) concepts and core data handling.

## Features
- **Book Inventory Management:** Add, view, and update book records.
- **Search Functionality:** Find books quickly by ID or title.
- **Borrow & Return Flow:** Track availability status and manage checkouts.
- **Clean Architecture:** Structured using OOP principles (Classes/Structs, Encapsulation, and Methods).

## Tech Stack
- **Language:** Swift
- **Environment:** Xcode / Terminal (macOS/Linux)
